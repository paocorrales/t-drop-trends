# Trends in temperature falls

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21713780.svg)](https://doi.org/10.5281/zenodo.21713780)

This repository contains the data and code for our paper:

> Corrales et. at., (2026). *Using rapid temperature falls to estimate future strong cold front frequency in CMIP6 climate projections*. 
> in review.

### How to cite

Please cite this compendium as:

> Corrales, P., et. al., (2026). *Compendium of R code for Using rapid temperature falls to estimate future strong cold front frequency in CMIP6 climate projections*. 

## Contents

* `download_data.R` includes the necessary code to download the derived (processed) data from Zenodo
* `article/main-article/`: Quarto source document for the manuscript. Includes code to reproduce the figures and tables
    generated by the analysis. It also has a rendered version,
    `article.pdf`, suitable for reading (the code is replaced by figures
    and tables in this file) 
* `src/` and `R/`: include the scripts and functions used to pre process the data (CMIP6 model experiments). They
are not needed to render the manuscript. 

## Running the code

Clone this repo. If using RStudio, open the project. 

### Installing R packages

This project uses the [renv](https://rstudio.github.io/renv/) package to manage a reproducible environment. If opening this project with RStudio or starting R from the command line from the root directory, renv should automagically install and load itself. 

To recreate the environment then run

```r
renv::restore()
```

This should install all the package dependencies needed to install the package and compile the document. Depending on your operating system, this could take a while. 

### Getting the data

To get the data needed to reproduce this paper is openly available in Zenodo at https://zenodo.org/records/21713532, version 2. You can download it by running `download_data.R`. The data will be stored in `data/`. 

### Render the manuscript

Finally, render the main manuscript located at `article/main-article/article.qmd` with:

```r
quarto render article/main-article/article.qmd
```
